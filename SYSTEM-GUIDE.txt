AFTER HOURS - CALL TRACKING SYSTEM - COMPLETE GUIDE
================================================================================

WHAT THIS SYSTEM DOES
---------------------
- After hours reps log incoming customer calls
- System sends SMS to the rep who owns that customer (via Twilio)
- Reps can REPLY to SMS to acknowledge receipt
- Morning dashboard shows all overnight activity grouped by rep
- Tracks all SMS messages sent with delivery status and replies

================================================================================

ACCESSING THE SYSTEM
--------------------
Live URL: https://phones-production.up.railway.app
Local Dev: http://localhost:5173

================================================================================

USER ROLES
----------
1. ADMIN - Can do everything including:
   - Add/edit/deactivate reps
   - Bulk import reps
   - View all dashboards

2. REP - Can:
   - Log calls
   - View dashboard
   - View SMS history

================================================================================

HOW TO LOG A CALL (Main Feature)
--------------------------------
1. Log in
2. You're on the "Log Call" page by default
3. Form defaults to "Unassigned / New Customer" with SMS unchecked
4. Fill in:
   - Customer Name (required)
   - Customer Phone (optional - for callback)
   - Select which rep owns this customer
   - Notes about the call
5. SMS behavior:
   - "Unassigned / New Customer" selected = SMS unchecked (no one to notify)
   - Any real rep selected = SMS auto-checked (will notify them)
6. Click "Save Call"

The customer's rep will receive an SMS like:
"Call from John Smith (555-1234) logged by Night Rep. Notes: Customer needs callback about order #123"

================================================================================

SMS ACKNOWLEDGMENT (Reply Feature)
----------------------------------
When a rep receives an SMS notification:
1. They can reply with ANYTHING ("OK", "Got it", "Thanks", etc.)
2. The system records their reply
3. Dashboard shows "Acknowledged" with their reply message
4. SMS History shows "Reply Received" and the actual reply

This lets you know the rep saw the message.

================================================================================

PAGES/FEATURES
--------------
1. LOG CALL (/) - Main screen for logging calls
2. DASHBOARD (/dashboard) - View all calls grouped by rep, filter by date
   - Shows SMS status (Sent, Acknowledged)
   - Shows reply message if acknowledged
3. SMS HISTORY (/sms-history) - See all SMS messages sent
   - Status: Sent or Reply Received
   - Reply: Shows actual reply message
4. MANAGE REPS (/reps) - Admin only - add/edit reps

================================================================================

ADDING NEW REPS
---------------

Option 1: One at a time
-----------------------
1. Log in as admin
2. Go to "Manage Reps"
3. Click "Add Rep"
4. Fill in name, email, phone, password
5. Click "Create"

Option 2: Bulk Import
---------------------
1. Log in as admin
2. Go to: https://phones-production.up.railway.app/api/bulk
3. Set a default password (e.g., "welcome123")
4. Paste reps in format: Name, Email, Phone
   Example:
   John Smith, john@company.com, +14155551234
   Jane Doe, jane@company.com, +14155555678
5. Click "Import Reps"

IMPORTANT: Bulk imported reps must change their password on first login.
Tell them: "Your login is your email. Password is welcome123. You'll change it on first login."

TWILIO CONFIGURATION
--------------------
Environment variables (set in Railway dashboard → Variables):
- TWILIO_ACCOUNT_SID=your_account_sid
- TWILIO_AUTH_TOKEN=your_auth_token
- TWILIO_PHONE_NUMBER=+14092634032

WEBHOOK FOR REPLIES:
To receive SMS replies, configure in Twilio Console:
1. Go to: console.twilio.com
2. Phone Numbers → Active Numbers → click your number
3. Messaging Configuration → "A message comes in":
   - URL: https://phones-production.up.railway.app/api/sms/incoming
   - Method: POST
4. Save

DATABASE
--------
SQLite database with 3 tables:
- reps: User accounts (name, email, phone, password, admin flag)
- calls: Logged calls (customer info, notes, timestamps)
- sms_log: SMS history (message, status, reply, acknowledged timestamp)
